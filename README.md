# 数学・数理演習 ランダム出題 (Math Quiz Web App)

提供された演習問題（線形計画法、数列、Σ記号、漸化式、極限、行列、確率・ベイズの定理、マルコフ推移行列、微積分、多変数関数など全102問）をランダムに出題し、自己学習・復習を効率的に行えるWebアプリケーションです。

---

## 🔒 プライバシーと他者との共有について

- **URLを他人に共有しても、進捗は一切混ざりません**:
  - 本アプリの学習データ（回答履歴、正答率、ブックマーク）は、閲覧している**各ユーザーのブラウザ・端末内（LocalStorage）に独立して保存**されます。
  - そのため、あなたが解いた履歴がURLを渡した相手に見られることは絶対にありません。
- **アカウント登録機能（複数ユーザー対応）**:
  - 1台のPCを家族や友人と共有する場合でも、**「ユーザー名」と「パスワード」のみ**で即座にアカウントを作成できます（メールアドレス不要）。
  - アカウントごとに学習データ・履歴が完全に分離して管理されます。

---

## 🌟 主な機能

1. **アカウント登録＆解答履歴タイムライン**
   - **簡単アカウント登録**: ユーザー名とパスワードのみですぐに登録・ログイン可能
   - **解答履歴タイムライン**: 何月何日何時何分にどの問題を解いて正解/要復習だったかを一覧表示。履歴をクリックすればその問題を再確認可能
   - **進捗の完全分離**: ユーザー切り替えでそれぞれの学習履歴を管理

2. **柔軟な出題モード**
   - **ランダム演習**: 全102問を重複なくランダムにシャッフルして出題
   - **10問チャレンジ**: ランダムに選ばれた10問を解き、最後にスコア・正答率を表示
   - **要復習リスト**: 間違えた問題やブックマークした問題だけを集中して演習

3. **分野別（章別）フィルタ**
   - 第1章: 線形計画法と領域 (6問)
   - 第2章: 数列・和の記号Σ・漸化式・極限 (22問)
   - 第3章: 行列とベクトル・ネットワーク分析 (8問)
   - 第4章: 指数・対数・三角関数・2次関数 (22問)
   - 第5章: 確率・条件付き確率・ベイズの定理 (10問)
   - 第6章: マルコフ推移行列・固有値・主成分分析 (10問)
   - 第7章: 微分・積分とその応用 (18問)
   - 第8章: 多変数関数・偏微分・最適化 (6問)

4. **快適な操作性**
   - **数式美麗表示**: KaTeXによるシグマ記号 $\Sigma$ や極限、積分の美麗レンダリング
   - **ワンクリック解答トグル**: 「解答を表示する」で解答と自己評価ボタンを展開
   - **キーボードショートカット**:
     - `Space`: 解答の表示/非表示
     - `Enter` または `→`: 次の問題へ
     - `←`: 前の問題へ
     - `1`: 「解けた」を記録
     - `2`: 「要復習」を記録（自動で要復習リストに追加）
     - `B`: ブックマーク登録/解除
   - **ダークモード / ライトモード対応**: ワンクリックで切り替え
